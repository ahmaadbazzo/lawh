# لَوح (Lawh)

**الحالة: قيد التطوير.**

لَوح تطبيق أعمل عليه لمساعدة المستخدم على الكتابة فوق الآيات مع إبقاء نص الآيات ظاهراً أمامه. الفكرة الأساسية هي أن تبقى الآيات واضحة أثناء الكتابة، لا أن تختفي بعد بدء الإدخال.

ما زلت أعمل على واجهة الكتابة وطريقة عرض النص، لذلك لا أعتبر المشروع إصداراً نهائياً أو جاهزاً للنشر حالياً.

## التقنية

- Flutter وDart
- واجهة عربية تدعم اتجاه RTL
- حفظ البيانات محلياً

## بنية المشروع

- `lib/screens/` للشاشات.
- `lib/providers/` لإدارة الحالة.
- `lib/services/` للخدمات والتعامل مع البيانات.
- `assets/` للخطوط والبيانات وملفات الواجهة.

## ملاحظة

هذا المستودع يعرض مرحلة العمل الحالية، وقد تتغير بعض التفاصيل مع استمرار التطوير.
